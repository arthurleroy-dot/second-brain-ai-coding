# Panorama des outils et acteurs de l'AI coding (note de veille)

Cette note recense, pour mémoire, les principaux outils, acteurs et briques techniques que je croise en ce moment autour du coding assisté par IA.

## Les éditeurs et agents de code

Côté outils, trois produits reviennent sans cesse dans mes lectures : Cursor, l'éditeur bâti sur un fork de VS Code ; Windsurf, son concurrent direct ; et GitHub Copilot, le pionnier de la complétion de code. J'utilise pour ma part Claude Code au quotidien, en ligne de commande. Un cran plus loin en autonomie, Devin se présente comme un « ingénieur logiciel autonome » capable de mener une tâche de bout en bout.

## Les entreprises derrière ces outils

Ces produits sont édités par une poignée d'entreprises. Anthropic, qui édite Claude Code, et OpenAI dominent la course aux modèles de fondation. Des acteurs plus jeunes émergent, comme Cognition, la société derrière Devin.

## Les modèles de fondation

Les modèles eux-mêmes évoluent très vite. GPT-5 du côté d'OpenAI, Gemini 3 du côté de Google, et Claude Opus du côté d'Anthropic sont aujourd'hui les moteurs qui font tourner la plupart de ces outils.

## Les briques techniques et les voix du domaine

Enfin, une brique technique structure désormais tout l'écosystème : MCP (Model Context Protocol), le standard ouvert qui permet à un agent de se brancher sur des outils et des données externes. Parmi les voix les plus suivies du domaine, Andrej Karpathy a popularisé l'expression « vibe coding » pour décrire cette nouvelle façon de programmer en s'appuyant sur l'IA.
